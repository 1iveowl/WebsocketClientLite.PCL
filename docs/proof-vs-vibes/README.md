# Proof vs. vibes

*Proof vs. vibes: assurance methods for AI agents* is a video series by Jasper H. Bojsen. It asks how you can
trust code an AI agent wrote without reading every line, and it uses this library as its worked example.

These pages are for viewers who come to the repository after watching. Each one follows an episode, points to
the files the episode shows, and says how to run the checks yourself.
